## What I Work On

- **Desktop software:** Cross-platform tray utilities, native macOS apps, and Windows tools.
- **Audio & input tooling:** MIDI-to-QWERTY routing, Wooting analog input handling, and audio transcription.
- **Roblox & Luau:** Client scripts, developer tooling, and MCP bridges.
